# Integration tests live in a separate Zig module

Integration tests (the four golden-snapshot ROMs at `tests/integration/golden_*.zig` plus `golden_harness.zig` and `scripted_input.zig`) live in `tests/integration/` as their own Zig module — wired into `zig build test` via a second `b.addTest` whose root is `tests/integration/root.zig` — and reach `chippy_core` only through its public API (`Machine`, `Framebuffer`, `assemble`, `ROM_MAX_BYTES`, `DISPLAY_WIDTH`/`HEIGHT`/`PIXELS`). Unit tests stay inline in `src/core/*.zig` where they need direct field access (`m.cpu.pc`, `m.bus.read8(...)`, `m.keypad.isAwaiting()`). Before this ADR the two surfaces were coresident in `src/core/`, which was Zig-idiomatic but let integration tests silently reach for internals — the discipline "integration tests use public API only" lived by reviewer attention. The split makes the public surface the literal integration-test surface; any failure to test through it now becomes a build error (the `tests/integration/` module cannot see `chippy_core`'s internals because they aren't re-exported via `root.zig`), not a convention violation. Rejected alternatives: status quo (mixed tree) keeps the public-API-only invariant social; a `src/core/goldens/` subdirectory is cosmetic because the files still inhabit `chippy_core`'s package directory. The trade-off is modest `build.zig` complexity (one second test source plus an `addImport("chippy_core", core_mod)` line) in exchange for structural enforcement of a discipline that grows costlier with each emulator rung. Carry-forward: the Game Boy walking-skeleton starts with this layout from day one — Mooneye / blargg / dmg-acid2 goldens go straight into `tests/integration/`; PPU / MBC / APU unit tests stay inline. The `tests/test_roms/` and `tests/test_goldens/` data directories are unchanged (ADR 0004); they were already siblings of `src/core/`, and the runtime relative paths (`cwd.readFileAlloc` with CWD = repo root) the harness uses still resolve correctly from the integration module's new location. This closes the architecture-deepening sweep PR #95 (Keypad privatization) and PR #97 (Bus privatization) opened: PR #95 + PR #97 made the per-module codec pattern carry-forward; this ADR makes the public-API-as-test-surface contract carry-forward.
