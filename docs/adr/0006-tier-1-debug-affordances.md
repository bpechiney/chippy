# Tier 1 debug affordances only; Tier 2 on demand, Tier 3 deferred to SNES

`chippy_core` ships Tier 1 debug affordances from day one, off by default so they're zero-cost when unused: a pure-function disassembler (`disasm(op: u16) DisasmEntry`), an opt-in trace writer (`Options.trace_writer` — one line per cycle: `pc op state-delta`), a textual state dump alongside `serialize`, a breakpoint hook (`Machine.runUntil(predicate)`), cycle and per-opcode counters, and a sprite-draw log for `DXYN`. Tier 2 (a CLI debug REPL over Tier 1) is built only if reality demands it; Tier 3 (a graphical / TUI debugger) is deferred to SNES, where address-space size and per-frame instruction count make a UI essential. The trade-off is less interactive debugging power on chippy in exchange for capping new concepts during the learning phase and avoiding tools that earn their keep on SNES but not on a 35-opcode emulator whose entire state fits in a `std.debug.print`.
