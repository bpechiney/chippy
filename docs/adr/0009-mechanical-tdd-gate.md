# Mechanical `/tdd` gate on issue branches

A project-level PreToolUse hook (`.claude/hooks/check-tdd-invoked.sh`) blocks `Edit`, `Write`, and `MultiEdit` on `src/**` while the current branch matches `^[0-9]+-` (the `N-slug` issue convention) until the current session's transcript contains a `Skill(skill="tdd")` invocation. ADR 0008 made `/tdd` the universal implementation method, but the mandate had no detection: an interactive session could read `~/.claude/skills/tdd/SKILL.md` and follow red-green informally while bypassing the formal `Skill` tool call, which silently dropped the skill's user-confirmation Planning phase (test list and interface design approved before code) and left no audit signal that discipline applied — the failure mode that cost the first M1 attempt an entire branch rollback. The hook closes that gap with the smallest possible surface: ~30 lines of bash, no global skill modifications, no CI changes, no commit-trailer scheme; it just inspects the transcript jsonl for the tool_use entry. Path scope is `src/**` only — covering production code and inline Zig `test "..." {}` blocks — leaving `tests/test_roms/` fixtures, `build.zig`, `flake.nix`, `docs/`, and `.claude/` editable on issue branches without ceremony. Branch scope is the numeric-issue prefix only, so master, refactor branches, and harness branches like the one this ADR ships on are never gated. Detection is per-session and non-idempotent: invocation in a prior session does not count, which is intentional — every fresh session re-runs the Planning gate, matching the "each new context confirms the contract" intent. Soft alternatives (warning-only hooks, audit-only Stop hooks, reviewer-agent transcript verification) were rejected because the M0 reviewer-agent gate has already proved leaky (see `docs/snes-handoff.md`) and the cost of a rollback dwarfs the cost of a hard block. A generic mandated-skill framework covering `/simplify`, `/commit`, `/commit-push-pr`, and `/review` was also rejected: per CLAUDE.md rule 9 ("three similar lines beats a premature abstraction"), generalize when a second skipped-skill failure justifies the framework, not before. The hook fails open whenever it cannot do its job — `jq` missing, transcript path absent, file outside the repo, git rev-parse failing — so a harness bug never silently masquerades as a discipline violation. The trade-off is one ceremonial `/tdd` invocation each time a fresh Claude Code session opens an issue branch, in exchange for a structurally impossible-to-skip Planning gate and a per-session audit trail that any reviewer can grep for.
