# Verification spine: opcode unit tests + Timendus golden snapshots + CI matrix via nix

Three layers, all in v1: (1) opcode unit tests — Zig `test` blocks, one per opcode family, each builds a tiny inline-assembled ROM, inits a `Machine` with a fixed `rng_seed`, runs N cycles, asserts state; (2) Timendus' `chip8-test-suite` ROMs vendored under `tests/test_roms/` and embedded via `@embedFile`, run headlessly with framebuffers compared to committed 256-byte golden snapshots (`UPDATE_GOLDENS=1` regenerates intentionally); (3) GitHub Actions on the public repo, matrix `ubuntu-latest` ∩ `macos-latest`, each running `nix develop -c zig build test` so the pinned Zig 0.16 in `flake.nix` is the single source of truth across laptop / CI / agents. Cross-emulator trace diff (against Octo) and property/fuzz testing are explicitly deferred — they're cheap to add later because the trace-writer is already core-side. The trade-off is upfront setup cost in exchange for an externally verifiable green-CI trust signal that lets agents' PRs be mergeable on green alone, which is the keystone of the AI-harness goal.
